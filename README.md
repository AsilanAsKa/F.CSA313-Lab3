## Алхам 3: SLO

| Сценарио     | SLI (юуг хэмжих)            | Босго        | Цонх / нөхцөл           |
| ------------ | --------------------------- | ------------ | ----------------------- |
| Performance  | `/cart/add` latency         | p95 < 200 ms | 20 VU, 1 минут          |
| Reliability  | `/pay` error rate           | < 8%         | 20 VU, 1 минут          |
| Availability | Бүх хүсэлтийн амжилтын хувь | ≥ 90%        | 2 минут, 10 сек зогсолт |

### Босго сонгосон шалтгаан

Performance-ийн 200 ms босгыг хурдан endpoint учраас сонгосон. `/pay` endpoint-д кодоор 5% алдаа үүсгэдэг тул 8%-ийн босго бодитой гэж үзсэн.

### Availability Error Budget

2 минут = 120 секунд.

Availability SLO = 90% учраас:

**Error budget = 120 × (1 - 0.90) = 12 секунд**

Тиймээс 2 минутын цонхонд сервер **12 секунд хүртэл** ажиллахгүй байж болно.
